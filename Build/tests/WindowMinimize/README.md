# 最小化与恢复回归检查

```powershell
./Build/scripts/purerdp.test.ps1 -Suite WindowMinimize
```

使用测试 WinForms 连接窗口和真实 HWND，不建立 RDP 连接、不保存用户设置。统一入口在不切换的独立桌面运行，最大化和模拟真全屏不会显示在用户当前桌面；不要绕过入口直接启动测试 EXE。检查未配对的绘制恢复不能显示隐藏窗口/画布、双窗口反复最小化、普通与最大化混合状态恢复、任务栏最小化恢复、模拟真全屏状态保留、快速连续切换，以及远程画布绘制锁不能移除顶层窗口可见性。

此测试能验证宿主窗口状态和绘制锁的 Win32 行为，不能替代真实 RDP 会话的闪烁和画面验收。

另从独立右下角拖动控件的原生鼠标消息入口验证拖动起点、主窗口尺寸变化及结束清理；不只调用内部尺寸计算方法。不会发送全局鼠标输入或操作用户当前桌面。

覆盖外部恢复后组布局暂停必须解除、未恢复兄弟窗口保持暂停，以及外部恢复→进入真全屏→退出时的尺寸、暂停标记和返回位置。全屏事件采用无连接服务强制事件路径，不进行远程登录。

重复 10 轮“窗口最大化（保留本机任务栏）→真全屏→窗口最大化”，检查宿主使用完整显示器边界、画布覆盖宿主且布局更新未暂停，退出时仍保持最大化。

另覆盖：组最小化后由任务栏恢复全部/部分窗口，再次执行快捷键必须首次最小化；模拟真全屏外部恢复后走异步快捷键执行路径，也应保持原状态。

窗口移动回归：仅九点区启动拖动、与按钮不重叠、远程画面点击不启动移动、普通窗口位置及尺寸、最大化后还原并继续移动、宫格只移动当前连接、Esc/结束清理、真全屏不消费鼠标消息。另覆盖控制栏留白原生点击/双击不捕获、角标与窗口命中测试不进入系统缩放、原生鼠标移动/释放驱动缩放、子窗口释放和取消清理。仅使用隔离桌面内的测试 HWND，不发送全局鼠标输入，不代表真实远程会话手感验收。

入口命中回归：将测试窗口置于隔离桌面有效屏幕范围，通过 `WindowFromPoint` 验证右下角中心和边缘真实命中角标，再向所命中的窗口发送完整拖动消息。收起控制栏覆盖首次显示尺寸、四种方向的原生命中、`12×44` 中间宽度、反复展开收起和隐藏重显尺寸不变、圆角透明度及悬停展开；实际合成帧输出至 `outputs/ui-review/ControlRail-*.png`。

自由缩放与记忆回归：仅两个 `5×5` 半透明底角；横向、纵向、非等比斜向拖动及左下对边锚定；手动记录序列化为内存 JSON 后重新应用，优先于连接的初始尺寸，切换无边框及退出真全屏不丢失位置/长宽。测试不读写真实用户的窗口状态文件。
