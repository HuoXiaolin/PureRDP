# PureRDP

新建设备时自动读取当前 Windows 用户的原生 RDP 地址历史，去重合并到地址下拉框，便于迁移添加；不会导入密码或修改系统历史，选择后仍需主动保存。

项目地址：[HuoXiaolin/PureRDP](https://github.com/HuoXiaolin/PureRDP)。全局设置中的“关于 PureRDP”提供作者与功能简介、手动检查更新和版本页面入口。检查只读取公开正式版 Releases，不会自动下载、安装或重启；发布标签请使用递增版本号（如 `v2.0.1`），同版本重新编译不会被识别为更新。

## 项目介绍

PureRDP 是面向 Windows 的远程桌面连接管理工具，适合需要经常访问多台电脑、服务器或运维设备的场景。项目以微软原生 RDP ActiveX 为连接核心，在此基础上提供设备库、多窗口管理、远程画面预览、状态观察和统一设置，减少重复填写连接信息与来回寻找连接窗口的操作。

## 主要功能

- 设备集中管理：支持设备名称、标记颜色、IP/域名和自定义端口，提供卡片、横排、列表视图，以及搜索、拖动排序、编辑和删除。
- 多连接窗口：支持多台设备同时连接，可选独立窗口或自动宫格布局，并提供连接切换、最大化、真全屏、批量最小化与原状态恢复等控制。
- 远程画面预览：设备卡片可显示只读预览；已有连接时复用会话，没有连接时可单独建立预览会话。
- 显示与缩放：支持动态分辨率、画面拉伸、默认画面缩放、宫格缩放和 DPI 设置，可按设备保存。
- 状态与日志：按配置周期检查 TCP 地址和端口，显示连接质量、带宽、延迟及探测丢包率；提供手动刷新和连接次数、时长、起止时间统计。
- 控制栏与快捷键：控制栏可置于窗口上下左右并居中，可选自动隐藏；PureRDP 快捷键支持自定义及冲突检查，普通 Windows 组合键按设备和窗口状态选择本地或远端处理。
- 本地资源重定向：可配置剪贴板、磁盘、打印机、智能卡、声音、麦克风和摄像头；实际可用性取决于服务端策略、驱动与远端应用。
- 连接重试：断线后采用递增间隔重试，最多 10 次；取消会关闭当前连接。控件明确报告远端关机时，不再自动重连。
- 配置与启动：支持标准 `.rdp` 文件、命令行入口、全局 JSON 设置导入/导出、系统托盘、单实例唤醒、登录 Windows 后自启动和静默启动。
- 数据位置说明：全局设置提供“数据与清理”页，可查看数据目录和日志位置、打开目录或复制路径，不自动删除数据。

## 项目优点

- 连接入口集中：把设备信息、连接操作、预览和状态放在同一控制台，减少重复输入与窗口查找。
- 适合多设备操作：独立窗口与宫格布局兼顾单台精细操作和多台并行查看，设备颜色与名称便于区分目标。
- 保留原生连接核心：使用 Windows RDP ActiveX，不另外实现 RDP 协议栈；认证和资源重定向由系统控件与服务端协商。
- 配置粒度清楚：设备设置与全局偏好分开，显示模式、键盘转发和本地资源可按设备配置，控制台偏好统一管理。
- 便于搬移与交付：当前采用免安装、不带运行时的单文件程序和普通文件夹交付；源码附同次编译程序，目标电脑仍需 .NET 10 Desktop Runtime x64。
- 数据可查、维护方便：配置与日志保存在本机，密码使用 Windows 凭据管理器，数据位置和清理注意事项可在设置中查看；源码保留构建脚本和回归检查，便于维护。

以上为现有功能与设计特点，不代表在所有 Windows、网络或远端策略下都具有相同兼容性，也不承诺比 `mstsc.exe` 更低的 CPU/内存占用或完全无闪烁。

## 快速运行

当前版本为 2.0.0。运行环境为 Windows x64、.NET 10 Desktop Runtime x64，以及系统提供的 RDP ActiveX 控件。Windows 11 是项目当前使用环境，其他系统版本需另行验证。远端须允许远程桌面连接，并满足账号、网络和服务端策略要求。

1. 打开 `D:\Agant\Github_Releases\PureRDP\`，双击 `PureRDP.exe`。
2. 点击“新建设备”，填写地址、用户名等信息并保存。
3. 在控制台选择设备进行连接；通过“编辑”调整设备设置，通过“全局设置”调整应用偏好。
4. 更新时先从系统托盘退出旧程序，再替换并启动最新版。

运行目录不加版本或时间后缀，默认只保留最新版；不提供压缩包，也不主动生成带运行时版本。免安装不等于无数据残留，清理前请查看“全局设置 → 数据与清理”。

## 开发与发布

需要 Windows 和 .NET 10 SDK，在仓库根目录运行：

```powershell
dotnet restore PureRDP/PureRDP.csproj -r win-x64
dotnet build PureRDP/PureRDP.csproj -c Release
./Build/scripts/purerdp.publish-portable-zh.ps1
```

源码交付目录为 `D:\Agant\Github_Source\PureRDP\`，内附同次编译的不带运行时程序。SDK 与输出目录可通过发布脚本参数调整，详见 [构建说明](README.zh-CN.md#从源码生成-exe)。
