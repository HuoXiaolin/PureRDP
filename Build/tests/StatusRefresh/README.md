# 控制台手动状态刷新回归检查

通过隔离桌面入口构建并运行（需要 .NET 10 SDK 和 Windows Desktop Runtime）：

```powershell
./Build/scripts/purerdp.test.ps1 -Suite StatusRefresh
```

检查本机临时 TCP 端口的在线/离线变化、并发扫描、空设备列表和关闭后的安全处理，以及离屏控件的按钮布局、刷新反馈、重复点击抑制、失败恢复、卡片保留和关闭中刷新。连接采样检查覆盖未连接/已释放会话安全退出，以及等待已有采样任务。

局域网扫描使用回环地址和临时 TCP 端口验证范围校验、开放/关闭端口、重复设备识别、临时连接与保存草稿。快扫使用虚拟网卡数据验证 DHCP 地址变化后重新读取网段，以及 Hyper-V 的 /20 范围完整计算。

不读取密码、不保存用户配置，也不建立实际 RDP 会话；本检查不能代替真实远程连接的网络指标验收。
