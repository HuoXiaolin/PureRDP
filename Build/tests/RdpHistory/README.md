# 原生历史与凭据回归

原生兼容检查使用同一个测试程序的 `--native-fixture` 分支作为自有子进程，验证参数往返、启动后解除调试、保留当前目录和退出码，以及仅限子进程的防递归环境标记。不会启动真实远程连接、写系统 IFEO、注入输入或读取进程内存。全套官方 MSTSC 参数逐组检查为内嵌或原生分流，未知字段、重复键和签名文件保留原始文件。

通过 `./Build/scripts/purerdp.test.ps1 -Suite RdpHistory` 在隔离桌面运行。

历史读取不写真实配置。凭据检查只创建唯一命名的 `.invalid` 演示端点，验证重复读取、端口/账号隔离、更新以及设备文件不包含明文密码；在 `finally` 中删除测试凭据和临时文件，不读取真实密码或替换原生 TERMSRV 项。

服务或受限 CI 令牌没有 Windows 凭据登录会话时，Win32 1312 会明确报告 `SKIP`；这不代表原生凭据验证通过，需在交互用户令牌下复测。其他错误仍使测试失败。测试不建立真实 RDP 会话。

路由参数测试仅使用临时目录中的虚构 `loadbalanceinfo`，检查带冒号及尾部空格的内容、命令行导入、会话克隆和设备/JSON 导出隔离，原始测试文件不应被修改。未连接 ActiveX 的实际属性传递检查位于 WindowMinimize 组；不使用真实堡垒机票据。

文件关联检查只检查内存中的注册计划，验证中文及空格路径的引号、Windows 默认应用注册入口和 Open With 声明，不写真实注册表，不修改 UserChoice 或原生 MSTSC 注册。
# 代理回归补充

加密密码回归使用当前测试用户临时生成的 DPAPI 数据，不读取真实会话文件或用户密码。检查 `.tmp` 导入、命令行合并、克隆、Unicode/空格保留、显式密码优先、JSON/现有导出文件隔离，以及损坏或无法解密数据的安全失败。

检查 MSTSC 启动参数转换、通用模板的身份/票据隔离，以及开启、重复开启、关闭恢复、空值类型恢复和第三方冲突。注册表写入仅发生在随机创建的 `HKCU/Software/PureRDP/RegressionFixtures/<GUID>` 根项内；引擎中的 IFEO 路径在该测试根项下面，不是系统 IFEO。测试结束删除这个确切的 GUID 项，不启用实际代理或修改默认应用，不运行 UAC。测试身份需有创建该临时项的权限。
