# PureRDP

外部普通 `.rdp` / MSTSC 连接默认先使用 PureRDP，首次连接失败再尝试原生；不能等价实现的安全模式等仍保留原生语义。详见 [RDP 兼容说明](docs/RDP-compatibility.md)；厂商现场自动登录仍需实际会话验收。

把常用远程桌面，集中到一个工作台。

PureRDP 是一款面向 Windows 的远程桌面连接管理工具。它以微软原生 RDP ActiveX 为连接核心，把设备管理、多窗口操作、只读画面预览和连接状态集中在一个中文界面中，方便日常办公、开发测试和多设备运维。

[项目主页](https://github.com/HuoXiaolin/PureRDP) · [版本下载](https://github.com/HuoXiaolin/PureRDP/releases) · [使用说明](README.zh-CN.md) · [更新日志](CHANGELOG.md)

## 为什么使用 PureRDP

当需要经常连接多台电脑时，重复输入地址、辨认窗口、查找连接配置，会让简单的远程操作变得繁琐。PureRDP 希望让这些工作更直观：用名称和颜色找到设备，在一个控制台查看状态，按自己的习惯安排连接窗口，并为不同设备保留各自的设置。

它不是新的远程桌面协议，也不替代 Windows 的远程桌面服务，而是在原生连接能力之上提供一个更集中的管理入口。

## 主要功能

- **设备集中管理**：为设备设置名称、颜色、地址和端口；支持卡片、横排和列表视图，以及搜索、拖动排序、编辑和删除。点击左上角小星星即可黄色置顶，常用设备优先展示，重启后保留。
- **便于迁移添加**：新建设备时自动读取当前用户的原生远程桌面地址历史，选择后填入对应用户名；已有 Windows 凭据可继续复用，密码不明文回显。
- **多窗口协作**：连接可使用独立窗口或自动宫格布局，支持窗口切换、最大化、真全屏，以及全部连接窗口的最小化与原状态恢复。
- **只读画面预览**：从设备卡片查看远程画面；已有连接时复用会话，没有连接时可单独建立只读预览。
- **状态与连接记录**：定时或手动检查设备 TCP 端口，查看连接质量、估算带宽、延迟和探测丢包率，并统计连接次数、起止时间与时长。
- **按设备调整体验**：分别设置分辨率、动态缩放、DPI、键盘转发、剪贴板，以及声音、麦克风、磁盘、打印机、智能卡和摄像头重定向。
- **统一操作习惯**：自定义 PureRDP 快捷键，设置控制栏的位置与自动隐藏；支持系统托盘、静默自启动、单实例唤醒和手动检查更新。
- **文件打开与启动代理**：控制台可打开 `.rdp` 文件；设置中可选择系统默认应用，并按需开启、恢复 MSTSC 启动代理，让直接调用原生客户端的助手转交连接。外部连接可统一使用通用显示与资源设置。
- **窗口外观与配置迁移**：连接窗口默认使用 16 像素圆角，保留底角自由缩放；支持命令行和全局 JSON 配置导入/导出，并提供数据目录与清理说明。

设备状态灯表示 TCP 端口可达性，不代表登录成功。外设重定向、认证及网络表现受 Windows、服务端策略和实际环境影响。

## 开始使用

1. 从[版本页面](https://github.com/HuoXiaolin/PureRDP/releases)获取程序，确保电脑具备 .NET 10 Desktop Runtime x64。
2. 运行 `PureRDP.exe`，点击“新建设备”，填写或选择连接地址，确认账号并保存。
3. 在控制台连接设备，通过“编辑”调整设备设置，通过“全局设置”调整窗口布局、快捷键和应用偏好。
4. 更新文件前，先从系统托盘退出旧程序。

当前默认交付 Windows x64、不带运行时的单文件程序，无需安装 MSI。远端电脑仍须开启远程桌面，并具备可用账号和网络访问条件。
